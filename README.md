# LeviVision

Plugin nativo para LeviLaunchroid, criado para oferecer opções visuais no Minecraft Bedrock.

> ⚠️ **Projeto desatualizado.** As informações de compatibilidade abaixo são antigas; o funcionamento em versões atuais do Minecraft, do launcher e do preloader não é garantido.

### Recursos planejados/implementados

- Visão noturna com opção de ativar e desativar
- Efeito X-Ray com controle de transparência
- Menu de configurações e botão flutuante
- Resource pack complementar

### Compatibilidade anteriormente declarada

- Minecraft Bedrock `1.21.100*`
- Android ARM64 (`arm64-v8a`)
- LeviLaunchroid com preloader Android compatível

Esses requisitos refletem a última configuração documentada e **não representam suporte às versões atuais**. O projeto deve ser tratado como experimental/arquivado até receber uma atualização e novos testes.
