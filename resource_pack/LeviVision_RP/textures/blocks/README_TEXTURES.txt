Tips
----
- X-Ray textures: keep alpha ~10–30% so stone is see-through but not invisible.
- Glow textures: boost saturation and brightness of the ore veins.
- True emissive RenderDragon materials may require MaterialBinLoader and
  custom .material.bin patches depending on the game build.
- Enable this pack in the world/global resource packs while using LeviVision.
